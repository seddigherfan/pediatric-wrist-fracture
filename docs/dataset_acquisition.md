# Dataset Acquisition

Primary source:

- Figshare record for GRAZPEDWRI-DX: <https://doi.org/10.6084/m9.figshare.14825193.v2>

Download policy:

- Prefer metadata inspection first.
- Preserve original archives in `data/raw/`.
- Avoid overwriting verified files.
- Use checksums when the source provides them.
- Support dry-run and metadata-only modes.

The acquisition record for this project is the Figshare v2 release of
GRAZPEDWRI-DX, with DOI `10.6084/m9.figshare.14825193.v2`.

Expected storage:

- The dataset contains 20,327 images and associated annotations, so practical free space should be verified before downloading.
- The downloader will report an estimated requirement from official metadata where available.
